# CSE4550_SleepTracker

Counting Sheep is an android application that gamifies healthy sleep habits. This application is geared towards people who have irregular or poor sleeping habits especially the young adult demographic. Users are able to log their sleep and make goals which on completion they will be rewarded with in-game digital currency which they can use to buy item from the shop. User will have their own digital room that they can decorate and show off all of their items.
